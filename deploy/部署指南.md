# 部署指南 —— 没有服务器也能上线

> 目标：把这个系统放到一个可公开访问的地址上。没有云服务器、没有备案、没有预算，也有办法做到。
>
> 文中数字都是本机实测的：首次请求触发模型加载 **48.9 秒**；两个模型合计 **3.4G**（去重后 2.2G）；54 条测试 **8.7 秒**跑完。

## 先选一条路线

| 路线 | 花钱 | 耗时 | 链接能活多久 | 适合 |
|------|------|------|--------------|------|
| **A. 内网穿透** | 0 | 10 分钟 | 电脑一关机就断，链接每次都不一样 | 临时演示 / 快速验证 |
| **B. 魔搭创空间** | 0（免费 CPU） | 40 分钟 | 长期固定 | **推荐：一个长期可访问的 demo 链接** |
| **C. Hugging Face Spaces** | 0（免费 CPU） | 40 分钟 | 长期固定 | 面向海外访问者 |
| **D. 自备云主机** | 百元级/年 | 1 小时 | 完全自主 | 想长期挂着，顺便练一次真运维 |

**建议顺序：先 A 验证一遍流程（10 分钟就有链接），再用 B 做长期链接。**

## 路线 A：内网穿透（10 分钟，0 成本）

原理：把本机 `8501` 端口映射到一个公网域名上。不用注册账号，Cloudflare 的临时隧道免费。

```powershell
# 1. 装 cloudflared（Windows 自带 winget）
winget install --id Cloudflare.cloudflared -e

# 2. 起界面。注意两个 false：不关掉的话，从公网域名访问会被 Streamlit 拦掉
streamlit run app.py --server.port 8501 --server.enableCORS=false --server.enableXsrfProtection=false

# 3. 另开一个 PowerShell 窗口，开隧道
cloudflared tunnel --url http://localhost:8501
```

第 3 步会打印一行 `https://xxxx-xxxx-xxxx.trycloudflare.com`，这就是你的公网地址，手机 4G 网络也能打开。

**注意：**

- 电脑不能睡、不能关机，命令行窗口不能关
- 链接每次重启都会变，演示前重新开一次就行
- 首次访问要等 30–60 秒（模型加载），别以为挂了

> 这条路线只适合临时演示——链接会失效，不能当长期地址用。它的主要价值是：10 分钟内验证「从公网能不能访问到我的系统」。

## 路线 B：魔搭创空间（推荐，0 成本 + 长期链接）

**为什么推荐：** 免费 CPU 实例、国内访问快、支持自定义 Docker、给一个固定 URL。国内网络环境下最省事。

### 1. 准备

- 注册 [modelscope.cn](https://www.modelscope.cn)（需实名认证，十几分钟）
- 本地先确认项目能跑：`streamlit run app.py`

### 2. 创建空间

网页右上角 → **创空间** → 新建：

- 空间名称：`rag-knowledge-qa`
- 许可证：MIT
- SDK：**Docker**（不是 Gradio）
- 可见性：公开

创建后会给你一个 git 地址，形如 `https://www.modelscope.cn/studios/<用户名>/rag-knowledge-qa.git`。

### 3. 推代码

```bash
git clone https://www.modelscope.cn/studios/<用户名>/rag-knowledge-qa.git
cd rag-knowledge-qa

# 把项目文件复制进来（models/ .venv/ data/ sessions/ 不要带，.dockerignore 已经排除了）
# Windows 上可以直接把项目文件夹里的内容拷过来

# 关键两步：用 space 专用文件覆盖
cp /d/develop/python/pythonProjects/ai/deploy/Dockerfile.space Dockerfile
cp /d/develop/python/pythonProjects/ai/deploy/space-README.md  README.md

git add -A
git commit -m "deploy: RAG + Agent demo"
git push
```

### 4. 配 API Key

空间页面 → **设置** → 环境变量 → 添加：

- 名称：`DEEPSEEK_API_KEY`
- 值：你的 `sk-xxxx`
- 勾选「私密」

**千万别把 key 写进 Dockerfile 或代码里**，那是公开仓库。

### 5. 等构建

首次构建 15–25 分钟，慢在两件事：`pip install`（torch 很大）和下载模型（2.2G）。

构建日志里应该能看到最后一行 `du -sh models` 打出 `2.2G` 左右——**如果打出 3.4G，说明去重那步没生效**。

### 6. 验证

打开空间页面，等 30–60 秒加载模型，然后上传一个 txt 问一句。顺便看一眼构建日志里有没有 `You can now view your Streamlit app`。

## 路线 C：Hugging Face Spaces（备选）

流程和 B 几乎一样，差别在配置文件和端口约定：

1. [huggingface.co/new-space](https://huggingface.co/new-space) → SDK 选 **Docker** → Hardware 选 **CPU basic（免费）**
2. `git clone https://huggingface.co/spaces/<用户名>/<空间名>`
3. 同样用 `deploy/Dockerfile.space` 覆盖 `Dockerfile`、`deploy/space-README.md` 覆盖 `README.md`
   （`space-README.md` 开头的 `sdk: docker` / `app_port: 7860` 就是 HF 认的配置，不能删）
4. Settings → **Variables and secrets** → 新建 Secret `DEEPSEEK_API_KEY`
5. push 后自动构建

**缺点：** 国内访问 `*.hf.space` 有时很慢甚至打不开，演示时体验不稳定。所以国内优先用路线 B。

## 路线 D：自备云主机（想长期挂着再看）

如果要买，**别买 2核2G**——rerank 模型加载后常驻约 1.5G，加上 torch 和 Python 进程，2G 机器会直接被 OOM Killer 杀掉。选 **2核4G**。

```bash
# 服务器上（Ubuntu）
curl -fsSL https://get.docker.com | sh
git clone <你的仓库>
cd <你的仓库>
cp .env.example .env && vim .env      # 填 DEEPSEEK_API_KEY
docker compose up -d --build
docker compose ps                      # 两个服务都该是 healthy
```

安全组要放行 `8000`（接口）和 `8501`（界面）。想用域名 + HTTPS，在前面加一层 Nginx 反向代理，再 `certbot --nginx` 签证书即可。

## 通用排错清单（三条路线都会踩）

| 现象 | 原因 | 怎么修 |
|------|------|--------|
| 页面白屏 / 一直转圈 | Streamlit 默认拒绝被嵌进 iframe | 启动参数加 `--server.enableCORS=false --server.enableXsrfProtection=false` |
| 端口不对 / 平台提示未监听 | 平台约定 7860，镜像里写的是 8000 | 用 `deploy/Dockerfile.space`，它已经把端口改成 7860 |
| 平台健康检查失败、反复重启 | 冷启动要 30–60 秒，探针 start-period 太短 | `HEALTHCHECK --start-period=90s`；平台侧把超时调大 |
| 容器被 OOM 杀掉 | rerank 模型约 1.5G | 环境变量加 `RAG_RERANK=0`，只做向量粗排，内存少一半 |
| 构建超时 | 模型 3.4G，pip 装 torch 慢 | 已做模型去重（2.2G）；再不行加 `--build-arg DOWNLOAD_MODELS=false`，模型改用层缓存或挂载 |
| 构建成功但报 `libgomp.so.1` 找不到 | slim 镜像缺 torch 的运行库 | Dockerfile 里已 `apt-get install libgomp1` |
| 重启后知识库空了 | 免费实例的磁盘是临时的 | 这是正常的。演示前重新上传一次，或用 `POST /knowledge` 脚本预置数据 |
| 报错「未配置环境变量 DEEPSEEK_API_KEY」 | secret 没加或没重启 | 加完 secret 要重启实例 |

## 附：本地先把服务跑通（部署前必做）

```bash
# 接口服务
uvicorn api:app --host 0.0.0.0 --port 8000
curl http://127.0.0.1:8000/health
# {"status":"ok","model":"deepseek-v4-pro","vector_backend":"numpy","chunks":0}

# 界面
streamlit run app.py
```

`/health` 里那个 `vector_backend` 字段是有意加的：万一平台上的 chromadb 没装上、静默退回了 numpy，你一眼就能看出来，而不是等到对比压测数据时才发现对不上。
